## 1. Core Analytics & Data Tools

### `get_daily_report`
Fetches canonical daily marketing metrics across all active connectors for a project.

```python
get_daily_report(
    project_id: str = "default",
    report_profile: str = "daily",
    date_from: str = "",
    date_to: str = ""
) -> dict
```

## 3. Governed Flow & Configuration Tools

### `flows_list`
Lists active datastreams and report configurations.

```python
flows_list(project_id: str = "default") -> list[dict]
```

### `flows_get`
Retrieves a specific datastream or report definition by ID.

```python
flows_get(project_id: str, flow_id: str) -> dict
```

### `flows_upsert`
Creates or updates a datastream configuration.

```python
flows_upsert(
    project_id: str,
    kind: str,  # "datastream" or "report"
    definition: dict
) -> dict
```

---

## 4. Connector Management & Verification Tools

### `connector_activate`
Activates an auto-discovered connector module for a project.

```python
connector_activate(project_id: str, provider: str) -> dict
```

### `connector_verify`
Runs immediate health checks and golden-pull validation for a connector connection.

```python
connector_verify(project_id: str, connection_ref_id: str) -> dict
```

---

## 5. Observability & Feedback Tools

### `submit_feedback`
Submits user rating (+1 / -1) and commentary on an agent analysis trace (AD-13).

```python
submit_feedback(
    trace_id: str,
    rating: int,  # 1 or -1
    feedback_text: str = ""
) -> dict
```
