# Design Token Pipeline

## Overview

This directory contains the single source of visual truth for the Connector widget platform (AD-11).

## Pipeline

```
Material Theme Builder (web UI)
         ↓  Export: "Design Tokens (W3C)"
   tokens.json  (W3C DTCG format)
         ↓  node ui/tokens/style-dictionary.config.js
   dist/theme.ts  (MUI v9 ThemeOptions)
         ↓  imported by ui/shell/src/theme.ts
   connectorTheme  (MUI Theme object)
         ↓  used by WidgetShell ThemeProvider
   every widget gets MD3 theming automatically
```

## Files

| File | Purpose |
|---|---|
| `tokens.json` | W3C DTCG token export (committed, source of truth) |
| `style-dictionary.config.js` | Build script that reads tokens.json and writes dist/theme.ts |
| `dist/theme.ts` | **Generated** — gitignored; regenerated by `pnpm build:tokens` |

## Regenerating

```bash
pnpm --filter @toorow/ui build:tokens
# or from the ui/ directory:
node tokens/style-dictionary.config.js
```

Run this before any widget build. In CI this step runs automatically before the bundle-check job.

## Token Format

`tokens.json` uses the [W3C Design Token Community Group (DTCG)](https://design-tokens.github.io/community-group/format/) format:

```json
{
  "md": {
    "sys": {
      "color": {
        "primary": { "$type": "color", "$value": "#6750A4" }
      }
    }
  }
}
```

Leaf nodes have `$type` and `$value` fields. Groups are plain objects.

## Why Not `mui-m3-theme`?

`mui-m3-theme` is **explicitly ruled out** (SOLUTION-DESIGN §4). The token pipeline uses plain Style Dictionary v4 to map MD3 color roles directly to MUI v9 palette roles — no third-party adapter library.

## MD3 → MUI Color Role Mapping

| MD3 role | MUI palette key |
|---|---|
| `md.sys.color.primary` | `palette.primary.main` |
| `md.sys.color.on-primary` | `palette.primary.contrastText` |
| `md.sys.color.surface` | `palette.background.paper` |
| `md.sys.color.background` | `palette.background.default` |
| `md.sys.color.error` | `palette.error.main` |
| `md.sys.color.warning` | `palette.warning.main` |

## Font Inlining

Roboto Flex and Material Symbols are inlined at widget build time via `@fontsource-variable/roboto-flex` and `@fontsource/material-symbols-outlined`. No CDN URL appears in the built bundle (NFR4 / AD-11).
